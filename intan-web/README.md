# INTAN Web — Frontend & 3D Interactive Platform

Website profil resmi dan platform visualisasi 3D digital twin untuk **INTAN (Smart Rotary Roaster)**, karya PKM-KI Universitas Padjadjaran 2026.

## 🚀 Panduan Memulai

```bash
# Masuk ke folder web
cd intan-web

# Instal dependensi
npm install

# Jalankan server pengembangan
npm run dev

# Jalankan build produksi
npm run build
```

Buka [http://localhost:3000](http://localhost:3000) pada browser Anda.

## 🛠️ Stack Teknologi
- **Next.js 16** (App Router)
- **TypeScript**
- **Tailwind CSS v4**
- **Three.js** (Simulasi 3D CAD)
- **Lucide React** (Ikonografi presisi)

## 📱 Responsivitas
Dioptimalkan penuh untuk semua ukuran layar (Desktop, Tablet, dan Smartphone / HP).
